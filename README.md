Hey y'all, I've been working for a bit on a module for ChatGPT I wanted to share with everyone!

The Image Scenario System, or ISS, is a drag and drop module that I've been using to help my workflow with generating images. 
It's got menus, organizational stuff, other random demos, all kinds of shit. 
I made it because I got tired of constantly doing trial and error with image gen stuff, and having a folder of notepads with prompt notes.
It was mostly a personal hobby project that ended growing, and I just felt like sharing in case other people liked it too.

## How to use
There is a text file and a zip file. Just drag and drop them both into ChatGPT and tell it to read the text and follow its' instructions. 
I tried to make this as painless of a process to use as possible.
The total module size is small enough you can even share the complete zip over Discord, shareware rocks baby.

NOTE: ISS is designed for ChatGPT *WORK MODE,* it does not function in normal chat mode! 
In chat mode ChatGPT cannot reliably parse file structures and complex instructions, it can *TRY* but it *SUCKS.*
Yes this means to fully use the ISS you need to be a ChatGPT Plus user, sorry. 

## Features
Scenario selection - It has a bunch of prompts I personally wrote for my own use, which I spent quite a lot of time tweaking to my tastes and refining. 
It also has features for auto correction and retrying prompts, so even the more risqué or complex ones turn out with consistent high quality results. 

Tools - A lot of post generation tools for various things. 
Subject and background transposition, surgical edits, post processing for emulating real photo imperfections, even a fursona generator because I felt like people might like that.

Demos - Random proof of concepts running inside of ChatGPT because I got kinda bored and insane working on this for a few weeks, check them out if you want.

All the pics in the thumbnail are generations made with ChatGPT using ISS scenarios and tools, using myself as a reference model.
